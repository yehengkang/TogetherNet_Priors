模块按职责拆分为若干独立文件，无包级 `__init__.py` 导出，调用方按需 import：
- `utils/utils.py`：纯函数库（图像色彩转换、letterbox resize、ImageNet 归一化、类别读取、优化器 lr 获取），被其他子模块复用。
- `utils/dataloader.py`：基于 `torch.utils.data.Dataset` 的 `YoloDataset`，实现随机缩放/裁剪/HSV 抖动以及 Mosaic 拼接，并输出 `(image, box, clearimg)` 三元组；配套 `yolo_dataset_collate` 用于 DataLoader。
- `utils/utils_bbox.py`：YOLO head 后处理——`decode_outputs` 将多尺度特征图展开为 `[N, anchors, C]` 并还原 xywh，`non_max_suppression` 使用 `torchvision.ops.boxes.batched_nms` 做置信度×类别分联合阈值 NMS，再经 `yolo_correct_boxes` 反 letterbox 回原图坐标。
- `utils/utils_fit.py`：单 epoch 训练+验证主循环，把 hazy 与 clear 图像拼接作为双分支输入，以 0.2·YOLO + 0.8·MSE(dehaze) 加权损失，并在每个 epoch 末尾按 `save_period` 保存 `logs/epXXX-lossX.XX-val_lossX.XX.pth`。
- `utils/callbacks.py`：`LossHistory` 类封装 TensorBoard `SummaryWriter`、逐 epoch 写入 txt 并用 matplotlib 绘制带 Savitzky–Golay 平滑的 loss 曲线。
- `utils/utils_map.py`：两套 VOC-style mAP 计算——`get_map` 直接解析 `ground-truth`/`detection-results` 文本目录并按 IoU≥MINOVERLAP 匹配 TP/FP，输出 AP/F1/Recall/Precision/lamr 图表；`preprocess_gt/preprocess_dr/get_coco_map` 将同格式文本转为 COCO JSON 后调用 `pycocotools.cocoeval`。
- `utils_coco/`：COCO 专用脚本——`coco_annotation.py` 把 `instances_train2017.json`/`val2017.json` 重映射到 11 类并生成 `coco_train.txt`/`coco_val.txt`；`get_map_coco.py` 继承顶层 `yolo.YOLO` 重写 `detect_image`，用 pycocotools 完成端到端 COCO val mAP 评测。
依赖方向单向：`dataloader → utils`；`utils_fit → utils + callbacks`；`utils_map / utils_coco → utils + utils_bbox`；各文件之间不互相引用，仅通过函数/类名耦合。
